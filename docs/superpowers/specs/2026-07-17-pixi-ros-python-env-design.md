# Design: pixi-based ROS (Humble/Jazzy) + Python environment

Date: 2026-07-17
Status: Approved (design)

## Goal

Let anyone build, test, and run this package with **no system ROS 2 install** by
provisioning ROS 2 and the Python/toolchain dependencies through
[pixi](https://pixi.sh) + [RoboStack](https://robostack.github.io/) conda channels.

- Support **ROS 2 Humble and Jazzy**.
- **Jazzy is the default** environment.
- **Full migration to pixi**: drop the previous dependency stack (rosdep + a
  `ros:humble` container in CI, and Poetry for Python). pixi becomes the single
  source of environment truth. `package.xml` is retained purely as ament build
  metadata consumed by colcon.

## Non-goals

- No CUDA/GPU features (unlike bagwiz).
- No multi-platform support beyond `linux-64` for now.
- No change to the node's runtime behavior or the metadata schema.

## Context

`co_mlops_rosbag_metadata` is a single ament_cmake package (Python node installed
via `ament_python_install_package`) with launch-based and pytest tests. Reference
pattern: the sibling `bagwiz` repo already uses pixi + RoboStack with per-distro
features and `default = ["jazzy"]`. This design mirrors that pattern, simplified
for a Python/ROS package (no C++ sources, no CUDA, no SLAM).

## Design

### pixi manifest (`pixi.toml`, new)

```toml
[workspace]
channels  = ["conda-forge"]
platforms = ["linux-64"]

[dependencies]            # distro-agnostic, inherited by every environment
colcon-common-extensions = "*"
cmake        = "*"
c-compiler   = "*"        # CMakeLists project() enables C/CXX by default
cxx-compiler = "*"
pyyaml       = "*"        # runtime: node imports `yaml`
pytest       = "*"        # dev/test
ruff         = "*"        # lint/format (config from pyproject.toml)
lark         = "*"        # lets pytest load the launch_testing plugin

[feature.humble]
channels = [{ channel = "https://prefix.dev/robostack-humble", priority = 1 }]
[feature.humble.dependencies]
# ros-humble-<pkg> mirror of package.xml
ros-humble-ros-base, ros-humble-rclpy, ros-humble-std-msgs,
ros-humble-ament-cmake, ros-humble-ament-cmake-python,
ros-humble-ament-cmake-pytest, ros-humble-launch, ros-humble-launch-ros,
ros-humble-ament-index-python, ros-humble-launch-testing,
ros-humble-launch-testing-ros, ros-humble-launch-testing-ament-cmake

[feature.jazzy]
channels = [{ channel = "https://prefix.dev/robostack-jazzy", priority = 1 }]
[feature.jazzy.dependencies]
# ros-jazzy-<pkg> mirror of the same set

[environments]
default = ["jazzy"]
humble  = ["humble"]
jazzy   = ["jazzy"]
```

Notes:

- **Python deps come from conda-forge `[dependencies]`** so they share the conda
  Python interpreter that RoboStack installs `rclpy` into. `pydantic` is **not**
  included (currently unused in code).
- Python version is **not pinned**; RoboStack resolves the correct interpreter
  per distro. ruff keeps `target-version = "py310"`.
- C/C++ compilers are included so `project(co_mlops_rosbag_metadata)` (which
  enables C/CXX by default) configures cleanly without editing `CMakeLists.txt`.

### Tasks

Each distro builds/tests into its own base keyed on `$PIXI_ENVIRONMENT_NAME`
(`build/<distro>`, `install/<distro>`) so switching `-e <distro>` never reuses
another distro's colcon/CMake cache.

- `build` — `colcon build --packages-select co_mlops_rosbag_metadata --cmake-args -DBUILD_TESTING=ON` into `build/<distro>` / `install/<distro>`.
- `test` — depends on `build`; `colcon test ...` + `colcon test-result --verbose`.
- `launch` — depends on `build`; sources `install/<distro>/setup.bash` then
  `ros2 launch co_mlops_rosbag_metadata co_mlops_rosbag_metadata_publisher.launch.xml path:={{ path }}` (`path` arg required).
- `lint` — `ruff check --config pyproject.toml`.
- `format` — `ruff format --config pyproject.toml`.
- `clean` — `rm -rf build install log`.

Usage: `pixi run build` (jazzy), `pixi run -e humble test`, `pixi shell -e jazzy`.

### Files changed by the full migration

| File                                | Change                                                                                                                                                                               |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `pixi.toml`                         | **New** manifest (above).                                                                                                                                                            |
| `pixi.lock`                         | **New**, generated by `pixi install` and committed.                                                                                                                                  |
| `rosdep.yaml`                       | **Delete** (pixi resolves dependencies).                                                                                                                                             |
| `.github/workflows/test.yaml`       | **Rename/replace** with `build.yaml`: `matrix: [humble, jazzy]`, `prefix-dev/setup-pixi`, `pixi run -e <distro> build` then `test`. (Required check name changes `test` -> `build`.) |
| `.github/workflows/release.yaml`    | Build job switched to pixi (drop the `ros:humble` container + rosdep registration).                                                                                                  |
| `pyproject.toml`                    | Remove `[tool.poetry]*` and `[build-system]`; keep only `[tool.ruff]*`.                                                                                                              |
| `poetry.lock`                       | **Delete**.                                                                                                                                                                          |
| `.pre-commit-config.yaml`           | Replace the local `poetry run ruff` hooks with the official `astral-sh/ruff-pre-commit` (`ruff-check` + `ruff-format`), config still from `pyproject.toml`.                          |
| `.github/workflows/pre-commit.yaml` | Remove the "Install Poetry and dependencies" step (no longer needed).                                                                                                                |
| `.gitignore`                        | Add `.pixi/`; confirm `build/`, `install/`, `log/` are ignored.                                                                                                                      |
| `README.md`                         | Rewrite Installation/Build/Test/Usage to pixi commands.                                                                                                                              |
| `AGENTS.md`                         | Update the dependency convention: pixi (RoboStack + conda-forge) manages ROS + Python; `package.xml` is ament build metadata.                                                        |

### Retained

- `package.xml`, `CMakeLists.txt` (consumed by colcon).
- All other pre-commit hooks; ruff configuration stays in `pyproject.toml`.

## Verification

- `pixi install` succeeds and `pixi.lock` is generated.
- `pixi run -e jazzy build && pixi run -e jazzy test` passes; same for `-e humble`.
- `pixi run -e jazzy launch path:=src/co_mlops_rosbag_metadata/test/fixtures/sample_metadata.yaml` publishes on `/metadata`.
- `pre-commit run --all-files` passes after Poetry removal.
- CI `build.yaml` is green on both humble and jazzy.

## Risks / open items

- RoboStack conda package names must match exactly per distro; a missing/renamed
  `ros-<distro>-*` package will surface at `pixi install` and needs adjustment.
- Renaming `test.yaml` -> `build.yaml` changes the required status-check name; any
  branch-protection rule referencing `test` must be updated by a maintainer.
- First `pixi install` and CI runs download sizable conda packages; CI relies on
  `setup-pixi` lockfile caching.
